# 오픈놀 커리어링크 관리자 페이지 (체험판)

오픈놀 커리어성장사업부 사후관리 관리자 페이지의 **가상 데이터 체험판**입니다.

- 모든 데이터는 가상이며 브라우저 안에서만 동작합니다. 새로고침하면 처음 상태로 돌아갑니다.
- 실제 데이터베이스(Supabase)와 연결되어 있지 않습니다.
- 체험 계정: `career@openknowl.com` 또는 `manager@openknowl.com` / 비밀번호 `careerlink2026!`

## 주의

- 이 저장소에는 **실제 수료생 명단, 백업 파일, 업로드 결과 파일을 절대 올리지 않습니다.**
  `.gitignore`가 엑셀·CSV 파일을 막아 두었습니다.
- 체험판 화면의 '엑셀 업로드'에는 가상 예시 파일만 사용하세요.
  (체험판은 서버에 저장하지 않지만, 시연 화면에 실제 개인정보가 보이지 않도록 하기 위함입니다.)
- 실제 운영 버전(STEP 4)에서는 Supabase 공개 키(anon key)만 코드에 들어가며,
  관리자 키(service_role key)는 절대 이 저장소에 넣지 않습니다.
