# 오픈놀 커리어링크 관리자 페이지

오픈놀 커리어성장사업부 사후관리 관리자 페이지입니다. 화면은 GitHub Pages, 데이터는 Supabase(서울 리전)에 저장됩니다.

## 동작 방식

- `config.js`에 Supabase 주소와 **공개 키**가 있으면 실제 DB에 연결됩니다.
- 두 값이 비어 있으면 가상 데이터 체험판으로 열립니다(저장되지 않음).
- 로그인은 Supabase Auth(이메일 + 비밀번호)이며, `admins` 테이블에 승인된 관리자만 데이터를 볼 수 있습니다.

## 보안 규칙

- `config.js`에는 공개 키(anon 또는 `sb_publishable_...`)만 넣습니다.
  **service_role 키, `sb_secret_...` 키는 절대 넣지 않습니다.** 넣으면 화면이 열리지 않도록 막혀 있습니다.
- 이 저장소에는 실제 수료생 명단, 백업 파일, 업로드 결과 파일을 올리지 않습니다. `.gitignore`가 엑셀·CSV를 막아 둡니다.
- 실제 명단은 관리자 페이지의 '엑셀 업로드'로만 Supabase에 넣습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 관리자 페이지 전체 |
| `config.js` | Supabase 연결 설정(공개 키만) |
| `.gitignore` | 개인정보 파일 업로드 방지 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내도록 하는 설정 |
